Why We Are Changing the Design & Palette

Global System

The current website uses a mix of generic teal/cyan accents and an outdated serif font (fontFamily: "Times New Roman, serif") across key sections. The UI lacks depth, modern motion hierarchy, and interactive 3D polish expected of an enterprise tech leader.

Current Visual Issues
  • Inline Times New Roman font applied arbitrarily on modern tech components.
  • Flat cards with standard light gray borders and static CSS shadows.
  • Basic 2D Swiper carousels with default arrow styling.
  • Lack of micro-interactions and 3D depth on user cursor movements.
New 3D & Framer Motion Rules
  • Typography: Plus Jakarta Sans (Clean UI Body) + Space Grotesk (Futuristic Display Headlines) + JetBrains Mono (Tech Specs).
  • Interactive 3D Tilt: Cards respond to mouse position using framer-motion spring physics (rotateX, rotateY, scale: 1.02).
  • Glassmorphism: Deep translucent background blur (backdrop-blur-xl bg-slate-900/60 border border-slate-700/50).
  • Floating 3D Elements: Floating tech cubes, holographic glows, and animated gradient mesh canvases.
